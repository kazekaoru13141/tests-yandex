# Дипломный проект по тестированию
Дипломный проект, посвященный тестированию функциональности интернет-маркетплейса Яндекс Маркет
## Цель проекта
Провести тестирование ключевых пользовательских сценариев яндекс маркета и автоматизировать наиболее стабильные из них​
